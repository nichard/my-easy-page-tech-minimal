# Tech Minimal

A simple, content-first homepage for software engineers and applied AI professionals. Technology styling is limited to a fine grid, a pulsing status indicator, and subtle hover motion.

The first screen prioritizes name, role, biography, location, current position, focus, experience, and contact links. Edit the sample content in `index.html` and the palette variables at the top of `style.css`. No build step is required.

## Companion Detail Page

This template includes `details.html`. Project, publication, article, demo, and profile-document links in the homepage open the matching section on this companion page. Keep the file beside `index.html` when publishing or forking the template.
